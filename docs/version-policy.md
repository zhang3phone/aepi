# 版本更新策略

本项目从 v0.1.17 之后采用每日汇总版本策略。

- 当天的功能调整、界面优化、提示词规则和部署修复先累计，不再每次单独递增版本号。
- 每天 21:00 作为版本节点，统一整理当天更新内容。
- 到版本节点时，再同步更新：
  - `package.json`
  - `package-lock.json`
  - `src/changelog.ts`
  - `D:\生图系统\版本备份` 中的版本备份包
- 版本备份仍然排除 `.env.local`、`.env`、日志、`node_modules` 等本地密钥或构建缓存文件。

日常小改动完成后可以先运行测试和构建确认可用；只有到 21:00 汇总版本时才升版本号和生成正式版本备份。
